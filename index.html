01

Fitmit

Live 2026

Pick a target size and get a file that fits under it. A lossless pass runs first, and when that is not enough a binary search across twelve quality settings finds the gentlest one that still meets the target, so twelve options resolve in at most four attempts. If the size is out of reach it reports the smallest the file can actually go rather than handing back something still too big. PDFs run through Ghostscript and images through Pillow, both behind one strategy interface, so the search is written once and adding a format means four methods. FastAPI with a Redis queue and a background worker on Render, React and TypeScript on Vercel, progress streamed over Server-Sent Events. Uploads delete themselves within ten minutes of finishing.

FastAPI · React · TypeScript · Redis · RQ · Ghostscript · Pillow · Docker · Render · Vercel

02

The Almanac

Capstone · 2025

Cloud data pipeline and forecasting platform, built as my capstone. A three-tier pipeline on Databricks and Azure Data Factory moves raw OHLCV data through PySpark indicators into Azure SQL, which cut data latency by 35%. A 2-layer PyTorch LSTM trained on 11,213 sliding windows of AAPL data predicts next-day price at 60-70% accuracy depending on the stock, validated with walk-forward cross-validation. Served through a Django REST API with a web client, a Flutter app, and Grafana and Power BI for monitoring.

PyTorch · LSTM · Databricks · Azure Data Factory · PySpark · Azure SQL · Django REST · Flutter · Grafana
