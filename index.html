Fitmit

Pick a target size and get a file that fits under it. A lossless pass runs first, and when that is not enough a binary search across twelve quality settings finds the gentlest one that still meets the target, so twelve options resolve in at most four attempts. If the size is out of reach it reports the smallest the file can actually go rather than handing back something still too big.

PDFs run through Ghostscript and images through Pillow, both behind one strategy interface, so the search is written once and adding a format means four methods. FastAPI with a Redis queue and a background worker on Render, React and TypeScript on Vercel, progress streamed over Server-Sent Events. Uploads delete themselves within ten minutes of finishing.

Financial Document Q&A

Answers plain-English questions over real SEC 10-K filings from JPMorgan, Goldman Sachs, MetLife, and others.

Retrieval runs BM25 and FAISS together with reciprocal rank fusion, which beat either method alone, and a locally hosted Gemma model streams the answers token by token. FastAPI backend, Streamlit frontend with company filtering and chat history, retrieval quality scored with RAGAS, all of it running in Docker.
