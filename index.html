Fitmit

Live 2026

Pick a target file size and get a file that fits under it.

  • A binary search across twelve quality settings finds the gentlest one that still meets the target, so twelve options resolve in at most four attempts
  • A lossless pass runs first, and when a target is out of reach it reports the smallest the file can actually go instead of returning something still too big
  • PDFs go through Ghostscript and images through Pillow behind one strategy interface, so adding a format means four methods
  • FastAPI with a Redis queue and a background worker, progress streamed over Server-Sent Events, uploads deleted within ten minutes

Capstone 2025
