FitFileSize

Live2026

Pick an upload limit and get a file that fits under it. PDFs and images, iPhone HEIC photos included, on its own domain with its own npm package.

  • Shipped as a product rather than a demo: seven file formats, 37 landing pages for specific limits, and 12 form presets (US visa DS-160, Indian e-Visa, IBPS, SBI, RRB, IRCC) that each set the size cap, the minimum size, and the exact pixel dimensions the form demands
  • Replaced blind bisection with a search that predicts the right setting from the sizes already measured. On production, a 5 MB photo to 200 KB fell from 9.2 s to 4.2 s, a 4.9 MB scan to 500 KB from 11.3 s to 4.9 s, and renders per run from four to two, with every output byte-identical
  • A limit chosen before upload starts the run while the visitor is still reading the size picker, which turns the wait after pressing Compress from 3.9 s into 0.3 s
  • Large photos are resampled in the browser before upload: a 10.7 MB 48 MP photo goes up as 1.5 MB, which on a 1.5 Mbit/s connection is 8.9 s instead of 57.7 s, verified to reach the same answer in 23 of 24 photo-and-limit pairs
  • An MCP server published to npm and listed in the official Model Context Protocol registry, so an AI assistant can fit a file to a form’s exact rules in one call
  • The API and two workers run in Docker Compose on a VPS behind a Cloudflare Tunnel, with the React frontend on Vercel. A watchdog restarts any container the health endpoint reports stuck, and an autodeploy ships main within two minutes of a merge

Cairn

Live2026

Self-hosted web analytics. Rust on Lambda, no cookies, no IP addresses stored, and it is counting this page view.

  • Ingest is one DynamoDB write per event. Bot filtering, user-agent classification, URL normalisation and visitor hashing are pure CPU with no I/O. Measured on arm64 at 128 MB: 184 ms cold start, 5.1 ms warm, 30 MB peak
  • Visitor IDs are a keyed BLAKE3 hash over site, address and user agent, under a salt derived from the UTC date, so IDs cannot be correlated across days. The persisted type has no IP field, and query strings are stripped before write
  • Tracker is 647 bytes gzipped, wraps pushState and replaceState for SPA route changes, and writes nothing to the browser
  • The scheduled rollup recomputes whole days from raw rows rather than incrementing counters, so re-runs are idempotent
  • 41 resources in Terraform: CloudFront, API Gateway HTTP API, three Lambdas on provided.al2023, DynamoDB, S3, EventBridge, one IAM role per function. $0/month on perpetual free tiers

Distill

2026

Invoices and receipts into structured data, with per-field confidence and a human review queue. Runs locally on one consumer GPU.

  • The model alone is 0.804 field F1. The system delivers 96.7% by auto-accepting only what it trusts and routing the rest to a person
  • Confidence is self-consistency agreement across k samples, capped when arithmetic or format validation fails. Trusted fields run 94.4% accurate against 54.1% for flagged ones, a 40-point separation that makes auto-accept safe
  • A subtotal equal to the total with no tax printed is arithmetically incoherent, so it goes to a human instead of into the books. The model does not have to be right, it has to know when it might be wrong
  • 175 tests, most written from real failures found in error analysis. CI re-scores frozen predictions on every push, so a change that silently moves a published number fails the build
  • Calibration measured rather than assumed: ECE 0.115 with a reliability table, and the accuracy-versus-coverage tradeoff shipped as an explicit dial with its exchange rate priced
  • Local inference at $0.00 per document, against roughly $0.004 on a hosted vision API
