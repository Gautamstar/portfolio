Worth knowing

Specific to Wise statements

Every institution prints something that trips up a naive conversion. These are the ones that come up with Wise.

One statement per currency balance

A multi-currency account produces a separate statement for each currency. Convert them separately and add a currency column yourself, or a licence lets you convert them in one pass — though the amounts will then sit in one column across currencies, which is rarely what you want for accounting.

Number format changes with the currency

A euro statement may print 1.234,56 where a sterling one prints 1,234.56. The format is detected per document, so you do not need to change the setting between files — but it is worth glancing at the Numbers control to confirm.

Conversions show both sides

Moving money between currencies appears in both statements, once as an outgoing and once as incoming. Expect to see each conversion twice across the set.

Questions

About Wise conversions

Is my Wise statement uploaded anywhere?

No. The conversion runs inside your browser tab using a PDF engine loaded with the page, and there is no server behind this site to receive a file. You can confirm it: open your browser's network panel before converting and you will see no request carrying the document. Once the page has loaded you can disconnect from the internet and it still works.

Which Wise statements does this work with?

Any Wise account statement saved as a PDF with a text layer, which is what you get when you download one from online banking. It is not written against a fixed Wise template — it reads the layout of the page itself, so it keeps working when the statement design changes. Scanned or photographed statements are images with no text to read and need OCR first.

Why not just download CSV from Wise?

Where that covers the period you need, do that instead — it is fewer steps. Wise offers CSV export for recent activity per balance. PDF statements are useful when you need a fixed document for a specific period. Converting the statement PDF is the route to periods the direct download will not reach, and it produces a file that matches the statement a lender or accountant has already seen.

Disclosures

  1. Scanned documents cannot be read. A PDF containing only page images has no text layer to extract. Apply OCR before converting.
  2. Password-protected files must be unlocked first. Remove the password in your PDF reader, then convert the unlocked copy.
  3. Statements written as prose will not parse. The parser requires dated rows carrying amounts; narrative summaries have neither.
  4. Automatic column reading is a starting point. Roles, number format and date order are inferred and presented for your correction. Check them against the statement before exporting.
  5. Verify totals before filing. This is a conversion tool, not a bookkeeping system, and no output should be relied upon for tax or audit purposes without being reconciled against the original document.
  6. This service is not a bank and is not affiliated with, endorsed by, or acting on behalf of any financial institution whose statements it converts.
