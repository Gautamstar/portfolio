Method

How a statement is read

Statements share no common format, so nothing here is written against a particular bank. The parser works from the geometry of the printed page, which is the one thing every statement has in common.

  1. STEP 01

    Rebuild the rows

    Every text run in the PDF carries a coordinate. Runs sharing a baseline are regrouped into rows, and runs whose boxes touch are merged, so a split Mar 15 becomes one date again.

  2. STEP 02

    Recover the columns

    Amounts are clustered by their right edge across the whole document. Statements right-align figures, so those clusters are the real columns — that is what separates debit from credit from balance without being told.

  3. STEP 03

    Hand it back for checking

    The roles it inferred are shown beside the values that produced them. You correct anything wrong and drop rows that should not be there, which is why layouts it has never seen still convert.

Questions

Before you send a statement anywhere

Is the file genuinely not uploaded?

Yes, and you do not have to take it on faith. Open your browser's network panel before converting: no request carries the document. The site is a set of static files with no backend, no database and no account system, so there is nowhere for a statement to be sent. Once the page has loaded you can disconnect from the internet entirely and it will still convert.

Which banks are supported?

It is not written per bank. It reads the layout of the printed page, so it handles most retail bank, credit card and brokerage statements, including ones it has never encountered. Where the automatic reading is wrong you correct the column roles yourself, which is why unfamiliar formats still work.

Nothing was found in my statement.

The usual cause is a scanned or photographed statement, which is an image with no text layer for any parser to read. Run the file through OCR first — Preview on macOS, Acrobat, and most scanner applications can add a text layer — then convert it here.

What exactly does the licence cover?

A key that removes the row limit and enables multi-file conversion, on every browser and machine you use, with no renewal and no expiry. Later versions are included.

Can I have a refund?

Within 30 days, without explanation. Because the free tier shows you every parsed row before you pay, you should already know whether it reads your statements correctly.

Disclosures

  1. Scanned documents cannot be read. A PDF containing only page images has no text layer to extract. Apply OCR before converting.
  2. Password-protected files must be unlocked first. Remove the password in your PDF reader, then convert the unlocked copy.
  3. Statements written as prose will not parse. The parser requires dated rows carrying amounts; narrative summaries have neither.
  4. Automatic column reading is a starting point. Roles, number format and date order are inferred and presented for your correction. Check them against the statement before exporting.
  5. Verify totals before filing. This is a conversion tool, not a bookkeeping system, and no output should be relied upon for tax or audit purposes without being reconciled against the original document.
  6. This service is not a bank and is not affiliated with, endorsed by, or acting on behalf of any financial institution whose statements it converts.
